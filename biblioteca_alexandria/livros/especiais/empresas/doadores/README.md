# Empresas e fundações doadoras

Cada organização possui diretório próprio. `eventos.compacto.json` usa uma lista de campos (`schema`) e linhas posicionais para reduzir repetição sem eliminar título, URL, data, status, prazo ou hash da evidência. O `dossie.md` mantém a leitura humana, padrões comprovados e lacunas.

Plataformas de divulgação não são classificadas como doadoras. Uma empresa só recebe histórico de doação quando a evidência primária identifica programa, objeto, valor (se publicado), forma de acesso e ano.
