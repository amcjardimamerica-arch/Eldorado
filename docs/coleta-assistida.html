Coleta assistida

Sites que o robô não pode ler — o robots.txt proíbe, a página só abre com JavaScript ou o site recusa até o IP brasileiro. Você abre a página no seu navegador e guarda o que ela mostra. Nada é burlado: é você lendo, no ritmo de uma pessoa.

1. Instale o botão (uma vez só). Arraste o botão abaixo para a barra de favoritos do Chrome.

Capturar indícios — Eldorado

Se a barra de favoritos não aparece: Ctrl+Shift+B (Windows) ou Cmd+Shift+B (Mac).
2. Para cada site da lista abaixo:
  1. clique em abrir; navegue pelas páginas de editais (no Prosas, passe as páginas da lista);
  2. em cada página, clique no favorito Capturar indícios — Eldorado. Um quadro mostra quantos editais foram guardados;
  3. no fim, clique em Baixar arquivo no quadro. O arquivo se chama indicios-site-data.json.
O Chrome salva na pasta escolhida em Configurações → Downloads. Para salvar na Área de Trabalho, escolha a Área de Trabalho ali (ou ligue "Perguntar onde salvar cada arquivo").
3. Envie o arquivo. Abra a página de envio, arraste o arquivo e clique em Commit changes. Em poucos minutos o motor importa os editais como indícios, e o Interceptador vai comprovar cada um na fonte oficial.

Abrir a página de envio (GitHub)

Pelo Claude no Chrome: peça "faça a coleta assistida do Eldorado" — o roteiro está em docs/indexadores/PROMPT-COLETA-ASSISTIDA.md.
